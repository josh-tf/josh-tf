## Featured Work
I build [Ticket Tool](https://ticket-tool.app), a Discord support platform with a visual flow builder and automation, and [Lateping](https://lateping.com), heartbeat monitoring for cron jobs, plus real-time alerting services for businesses, from monitoring through to Discord and push delivery, all running at the edge.

Open source: [FXCommands](https://github.com/josh-tf/fxcommands), a Stream Deck plugin for FiveM and RedM on the [Elgato Marketplace](https://marketplace.elgato.com/product/fxcommands-3c018041-5776-412f-ad1b-1c0da734040b), and [Teleport Logistics](https://github.com/josh-tf/teleport-logistics), an Unreal C++ mod for Satisfactory.

Most of my work is private: Ava and Jarvis (personal and business AI assistants), content pipelines, e-commerce automation, Cloudflare projects, developer tooling, game servers, and the infrastructure it all runs on.
